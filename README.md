Chapitre 2 : Protection de la transmission réseau

Transmission réseau : les données circulent entre le client et le serveur de base de données. Par défaut, ce trafic peut passer en clair (identifiants, requêtes, résultats).

Enjeux de sécurité :

Confidentialité : empêcher la lecture des données par un tiers.
Intégrité : garantir que les données ne sont pas modifiées en transit.
Disponibilité : maintenir l’accès au service.
Authentification : vérifier l’identité du client et du serveur.
